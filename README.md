# Freelance HQ

A private workspace for freelance work: projects and clients, a job-application tracker with a job-site links hub, tasks, a calendar, chat, and invoices/earnings.

Plain HTML, CSS and JavaScript modules. Data and sign-in are Firebase (project `freelance-hq-57931`); who can sign in is set on the People page and enforced by `firestore.rules`. Hosted on Netlify from this branch.
